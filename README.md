# InternLink

A web-based intern management system developed during my internship at the East Java Province Public Works Department.

## 📌 Overview

InternLink is a website for displaying data on interns at the East Java Province Public Works and Highways Agency.

## ✨ Features

- User Login
- Dashboard
- Intern Management
- Search Intern
- Create a Sertificate
- Responsive Design

## 🛠️ Tech Stack

- HTML
- CSS
- Bootstrap
- JavaScript

## 👩‍💻 My Role

Front-End Developer

Responsibilities:

- Developed responsive user interfaces
- Designed website layouts
- Integrated frontend with backend
- Improved website responsiveness
